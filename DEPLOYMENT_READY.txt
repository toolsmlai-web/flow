IMPORTANT REMINDERS
================================================================================

1. Database Tables
   - Tables must be initialized via SQL in Supabase
   - This is step 3 above
   - Without this, form submissions will fail

2. Resend API Key
   - Must be added to Vercel environment variables
   - Without this, email service won't work
   - Signup still succeeds, but email won't send
   - Can be added anytime after deployment

3. Domain/DNS
   - If using custom domain, ensure DNS points to Vercel
   - Vercel provides DNS instructions
   - SSL certificate auto-generated
   - Usually takes <24 hours to propagate

4. Costs
   - Supabase: $25/month (database)
   - Resend: $20/month (email, first 100 free)
   - Vercel: $20/month (hosting)
   - Upstash: Free-$10/month (optional)
   - Total: $65-95/month expected

5. Monitoring
   - Vercel Analytics: Free, automatic
   - Supabase Logs: Dashboard → Logs
   - Email: resend.com dashboard
   - Errors: Vercel error logs
